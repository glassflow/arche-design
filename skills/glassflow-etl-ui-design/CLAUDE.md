# glassflow-ui Design System (legacy — ClickHouse ETL UI)

This directory holds the **glassflow-etl-ui-design** skill: the design system of GlassFlow's
first product, the ClickHouse ETL UI, extracted by skillui. Dark warm-glass theme, Archivo + Inter,
`#ffa24b` accent.

It is NOT the system of Rius or Tares. Those use `skills/glassflow-paper-design` in the arche-design repo (installed as `~/.claude/skills/glassflow-paper-design`).

## How to use

Read `SKILL.md` in this directory for the full design system reference before writing any UI code
for the ETL UI.

Key files:
- `SKILL.md` — master design reference (read this first)
- `references/DESIGN.md` — extended tokens and component specs
- `fonts/` — bundled Archivo and Inter cuts
- `screenshots/` — reference captures (study before implementing)

When building ETL UI surfaces, always read SKILL.md first and match colors, fonts, spacing, and motion exactly.
